# Ucapan Ulang Tahun Romantis ❤️

Paket final sudah berisi `index.html` dan `music.mp3`.

## Upload ke GitHub
Upload isi folder ini ke repository GitHub:
- `index.html`
- `music.mp3`

Opsional: tambahkan `foto1.jpg`, `foto2.jpg`, `foto3.jpg` jika ingin galeri foto.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/(root)`.

## Musik
Website mencoba memainkan `music.mp3` otomatis saat halaman dibuka. Jika browser memblokir autoplay bersuara, musik akan mulai pada interaksi pertama (tap/klik/keyboard). Ini merupakan pembatasan browser dan tidak dapat dipaksa oleh JavaScript.

## Lilin
Fitur tiup lilin memakai microphone + Web Audio API. Gunakan HTTPS (GitHub Pages) dan izinkan microphone.
